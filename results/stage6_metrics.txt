BUG FOUND AND FIXED in scripts/check_offline.sh: the Prometheus image has no bash, so the probe
could not start, and the old script still printed "prometheus cannot reach the internet". It
now runs the probe from a helper container joined to each service's network
(--network container:<id>), and counts a service as blocked only on "Network is unreachable".
Any other outcome is a FAIL. Stage 5's result stands: db, litellm and ollama were each checked
by hand at the time to be "Network is unreachable".
Proof the fixed check catches a leak: Prometheus connected to Docker's normal network on purpose
-> "FAIL prometheus reached the internet", exit 1. Disconnected -> PASS.
